ThemeBulletin is designed to make theme discovery fast and visual. The gallery opens on a category overview board, and from there you can drill into any of the four categories to browse individual theme cards on paginated boards. This guide walks through every interaction in the gallery — from picking a category to opening a live demo — so you can find the perfect portfolio design efficiently.

## Step 1: Choose a Category

When you first open ThemeBulletin, the pinboard displays four large sticky notes — one for each category. Each note shows the category name and the number of themes it contains.

Click any category note to open that category's theme board. Alternatively, use the **category navigation bar** at the top of the page — it lists all four categories with their counts, plus an **All Categories** button to return to the overview at any time.

## Step 2: Read the Polaroid Cards and Sticky Notes

Each theme in a category board is displayed as a **theme-pin pair**: a polaroid photo card pinned alongside a sticky note.

**The polaroid card** gives you an immediate visual impression of the theme. It shows:
- A full-color screenshot of the theme's homepage
- The theme name as a printed caption below the image, in the style of a handwritten photo label

**The sticky note** gives you navigational context. It shows:
- The category as a small eyebrow label
- The theme name as a heading
- A "View Theme Details →" link prompt

Both the polaroid and the sticky note link to the same destination: the theme's individual detail page. Click either one to learn more.

<Tip>
  If a preview image fails to load (for example due to a slow connection), the polaroid displays a "Homepage screenshot unavailable" fallback text so you always know a card is present.
</Tip>

## Step 3: Paginate Through Boards

Categories with more than 16 themes are split across multiple boards. The **Retro & Gaming** category (22 themes) currently spans two boards. A status label below the pinboard tells you exactly where you are, for example:

```
Retro & Gaming • Board 1 of 2
```

Use the **← Previous Board** and **Next Board →** buttons to move between pages. The buttons are disabled when you are at the first or last board, respectively. The pagination controls are hidden entirely for categories that fit on a single board.

## Step 4: Explore a Theme Detail Page

Clicking a polaroid or sticky note opens that theme's individual detail page. Each detail page is structured as a static pinboard with five sections:

<Steps>
  <Step title="Polaroid Preview">
    A large screenshot of the theme's homepage, displayed as an oversized polaroid card pinned to the board.
  </Step>
  <Step title="Title Note">
    The category label, theme name, and one-sentence summary — the core identity of the theme at a glance.
  </Step>
  <Step title="At a Glance">
    A structured overview confirming the category, format (standalone static website), and hosting platform (GitHub Pages).
  </Step>
  <Step title="Design Highlights">
    A bullet list of the theme's key design and structural properties, including its visual identity, responsive layout approach, and portfolio-ready sections.
  </Step>
  <Step title="Explore the Theme">
    Two action links — **Open Live Demo** and **View GitHub Repository** — that open in a new tab so you never lose your place in the gallery.
  </Step>
</Steps>

## Tips for Comparing Themes

**Open multiple detail pages in separate tabs.** The most effective way to compare two designs side by side is to click each theme's polaroid or sticky note with `Cmd+Click` (macOS) or `Ctrl+Click` (Windows/Linux) to open the detail page in a new tab. You can then switch between tabs to compare screenshots and highlights.

**Use the live demo links.** Every theme has a deployed live demo hosted on GitHub Pages. Opening the live demo gives you the real interactive experience — hover states, scroll behavior, and any dynamic UI elements — that a static screenshot cannot show.

**Check the GitHub repository before forking.** The repository link on each detail page takes you directly to the theme's source code. Before forking, you can browse the file structure, read any inline comments, and confirm the HTML sections match what you want to customize.

<Info>
  All theme detail pages include a **← Back to Theme Boards** link in the top-left corner of the pinboard, so you can return to the gallery without using the browser back button.
</Info>
