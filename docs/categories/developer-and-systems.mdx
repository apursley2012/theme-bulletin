The Developer & Systems category contains 13 portfolio themes that draw their visual identity from the tools, interfaces, and environments that developers work in every day. These designs translate the aesthetics of operating systems, terminal windows, technical dashboards, classified documents, and developer workspaces into polished personal portfolio pages. Whether you want to present yourself as an engineer operating a command center or a craftsperson building software by hand, this category has a design to match.

<Info>
  All 13 themes are fully static websites hosted on GitHub Pages. Each has its own live demo and standalone repository. See [Deploying to GitHub Pages](/using-themes/deploying-to-github-pages) to get started.
</Info>

## All 13 Themes

<Accordion title="Developer Dossier">
  **Summary:** A classified-file portfolio that presents projects, experience, and technical strengths as a polished professional dossier.

  The Developer Dossier theme frames your portfolio as a confidential intelligence file — complete with case-file panels, structured information sections, and a controlled, investigative visual tone. It is a strong choice for developers who want to present credentials in an organized, authoritative way.

  - **Live demo:** [apursley2012.github.io/developer-dossier](https://apursley2012.github.io/developer-dossier/)
  - **Repository:** [github.com/apursley2012/developer-dossier](https://github.com/apursley2012/developer-dossier)
</Accordion>

<Accordion title="Developer.exe">
  **Summary:** A neon executable-style portfolio with a focused launch-screen introduction and crisp system-inspired navigation.

  Developer.exe frames your portfolio as a running executable — opening with a launch screen that introduces you directly before transitioning into the main interface. The neon color palette and system-inspired navigation give it a sharp, modern technical edge.

  - **Live demo:** [apursley2012.github.io/developer-exe](https://apursley2012.github.io/developer-exe/)
  - **Repository:** [github.com/apursley2012/developer-exe](https://github.com/apursley2012/developer-exe)
</Accordion>
