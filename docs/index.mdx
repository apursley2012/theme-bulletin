Each theme is a complete, self-contained static site with its own unique visual personality — from classified developer dossiers and retro Windows desktops to cosmic starfields and spellbook-inspired layouts. Browse by category, preview every design, and fork the one that fits you.

## Get a Theme Live in Three Steps

<Steps>
  <Step title="Browse the Gallery">
    Open the [Theme Gallery](/themes/developer-dossier) tab and explore themes by category. Click any polaroid or sticky note to open the full theme profile with a screenshot, summary, and links.
  </Step>
  <Step title="Preview the Live Demo">
    Every theme has a hosted live demo linked directly from its profile page. Open it to see the full design in your browser before committing to anything.
  </Step>
  <Step title="Fork and Deploy">
    Click the GitHub repository link on the theme's profile page. Fork the repo, enable GitHub Pages in your repository settings, and your portfolio is live. See the [deployment guide](/using-themes/deploying-to-github-pages) for detailed instructions.
  </Step>
</Steps>

<Note>
  Every theme in ThemeBulletin is a standalone static website — no build tools, no dependencies to install, no frameworks to learn. Just fork, edit the HTML/CSS, and push.
</Note>
